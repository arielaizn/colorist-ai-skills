# Colorist AI Skills

חבילת סקילים לעבודה עם סוכן AI כעוזר קולוריסט: קבלת חומר מצולם, אבחון מקור, תיקון צבע, בניית לוק, בקרת איכות וייצוא.

## התקנה

העתיקו את התיקייה `color-grading-assistant` אל תיקיית הסקילים של הסוכן שלכם. הסקיל אינו מתקין תוכנה, אינו משנה קובצי מקור ואינו מרנדר בלי אישור מפורש.

## מבנה

- `color-grading-assistant/SKILL.md` — תהליך העבודה והחלטות מרכזיות.
- `references/workflow.md` — תהליך Resolve ומסלול עיבוד ישיר לקובץ.
- `references/camera-notes.md` — קליטת חומר מטלפונים, Log, RAW ומצלמות שונות.
- `references/quality-and-export.md` — בדיקות, תיקונים, LUT וייצוא.
- `templates/brief.he.md` — שאלון/בריף שאפשר להעתיק לכל פרויקט.

## ייחוס

החבילה נכתבה מחדש על בסיס עקרונות עבודה של מדריך הצבע של [איל ברגר](https://www.ebergerstudio.com/color-guide.html), לצד תיעוד יצרנים רשמי. היא אינה העתק או תרגום של המדריך ואינה קשורה רשמית ליצרני המצלמות או התוכנות.
